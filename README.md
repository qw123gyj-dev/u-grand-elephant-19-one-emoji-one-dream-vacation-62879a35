# One Emoji, One Dream Vacation

Exactly one emoji, nothing else, standing in for the trip of your dreams. `main.ts` (Node 22, stdlib only, no network) writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single emoji grapheme within the gate's 1-to-8-character window and not only white space, reads it back and verifies the bytes match.
